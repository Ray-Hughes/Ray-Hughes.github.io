# Ray-Hughes.github.io

Personal portfolio and resume site for **Raymond Hughes** — AI Engineer, Solutions Architect, and Ruby on Rails Tech Lead.

**Live:** [ray-hughes.github.io](https://ray-hughes.github.io)

---

## About

An interactive AI-themed portfolio showcasing professional experience, skills, and featured projects. Built with a neural-network canvas background, typewriter animations, and a dark terminal aesthetic.

**Sections:**
- Hero with animated neural network and typewriter role cycling
- Professional summary and career stats
- Full experience timeline (VA Appeals / Take2 Consulting, Carepaths Inc., and more)
- Featured projects: [Patientevity](https://github.com/Patientevity) and [Memophor](https://github.com/memophor)
- Technical skills across AI & Agents, Backend, Frontend, Cloud & DevOps, Healthcare, and Leadership
- Contact section with resume download

---

## Stack

- **React 19** + **Vite 6**
- Custom CSS — Orbitron / Syne / JetBrains Mono font stack
- Canvas API — animated neural network background
- GitHub Actions — automated build and deploy on push to `main`

---

## Development

```bash
npm install
npm run dev       # http://localhost:5173
```

## Deployment

Push to `main`. GitHub Actions builds with Vite and deploys to GitHub Pages automatically.
